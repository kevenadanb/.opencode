## Etapa 1 • Inventário do Design System

Antes de realizar qualquer modificação, faça uma análise completa do sistema atual.

Mapeie:

### Estrutura

- páginas
- frames principais
- fluxos
- módulos

### Design System

- componentes existentes
- variantes
- tokens
- estilos globais
- tipografia
- espaçamentos
- grids
- ícones
- padrões recorrentes

### Governança

Identifique:

- duplicidades
- inconsistências
- anti-patterns
- componentes obsoletos
- desvios visuais
- problemas de manutenção

Utilize o Design System já existente como fonte primária de verdade.

---

## Restrições Obrigatórias

### NÃO FAZER

- Não alterar a identidade visual da empresa.
- Não alterar a paleta principal.
- Não alterar branding.
- Não criar redesign completo.
- Não reconstruir a interface do zero.
- Não substituir padrões já consolidados sem justificativa.

### FAZER

- Evoluir.
- Refinar.
- Padronizar.
- Organizar.
- Simplificar.
- Melhorar usabilidade.
- Aumentar consistência.

## Critérios de Avaliação

Analise e identifique problemas relacionados a:

### Layout

- alinhamento
- grids
- composição
- distribuição visual
- responsividade

### Tipografia

- escala tipográfica
- pesos inconsistentes
- line-height inadequado
- hierarquia textual

### Espaçamento

- ausência de padrão
- margens inconsistentes
- paddings irregulares
- quebra de rhythm visual

### Componentes

- botões
- inputs
- selects
- tabelas
- modais
- badges
- cards
- tooltips
- menus
- navegação

### Consistência

- estilos divergentes
- tamanhos diferentes para funções iguais
- estados ausentes
- comportamentos inconsistentes

### Acessibilidade

- contraste
- legibilidade
- áreas clicáveis
- foco
- navegação
- semântica visual

### Experiência do Usuário

- excesso de ruído visual
- sobrecarga cognitiva
- baixa escaneabilidade
- fluxo confuso
- hierarquia inadequada

## Regras de Padronização

### Grid

Aplicar escala baseada em:

- 4px para microajustes
- 8px para layout
- Auto Layout sempre que possível

### Hierarquia

Garantir:

- leitura rápida
- agrupamento correto
- foco visual adequado
- escaneabilidade

### Componentização

Priorizar:

- reutilização
- escalabilidade
- consistência
- manutenção futura

### Responsividade

Validar:

- desktop
- tablet
- mobile

Quando aplicável.

---

## Execução

Ao encontrar um problema:

1. Identifique.
2. Classifique impacto.
3. Corrija.
4. Padronize.
5. Reutilize componentes existentes.
6. Evite criar novos componentes sem necessidade.

Sempre escolha a solução de menor impacto visual e maior ganho de consistência.

## Critério Principal de Sucesso

A interface final deve transmitir a sensação de que:

- sempre pertenceu ao produto;
- está mais organizada;
- está mais consistente;
- está mais moderna;
- está mais fácil de usar.

O resultado deve parecer uma evolução profissional do design existente, nunca um redesign completo.
