# Changelogs

Histórico de mudanças de cada projeto.

## 📂 Estrutura

Cada projeto tem seu próprio diretório `projeto`

## 📝 Formato

Use o padrão [Keep a Changelog](https://keepachangelog.com/pt-BR/):

```markdown
# Changelog

## [Unreleased]

### Added

-    Nova funcionalidade X

### Changed

-    Alteração na funcionalidade Y

### Fixed

-    Correção do bug Z

## [1.0.0] - 2025-01-15

### Added

-    Funcionalidade inicial
```

## 🏷️ Categorias

-    **Added** - Novas funcionalidades
-    **Changed** - Mudanças em funcionalidades existentes
-    **Deprecated** - Funcionalidades obsoletas (serão removidas)
-    **Removed** - Funcionalidades removidas
-    **Fixed** - Correções de bugs
-    **Security** - Correções de segurança

## 💡 Dicas

-    Escreva para usuários, não desenvolvedores
-    Use linguagem clara e objetiva
-    Inclua links para issues/PRs quando relevante
-    Mantenha ordem cronológica (mais recente primeiro)
