# Instruções

Este diretório contém instruções que orientam sobre padrões de código, boas práticas e convenções dos projetos.

## 🔧 Como Funcionam

É carregado automaticamente estes arquivos quando você trabalha no workspace. Eles influenciam as sugestões de código e respostas para manter consistência com os padrões do projeto.

## ✏️ Criando Novas Instruções

1. Crie um arquivo com sufixo `.instructions.md`
2. Use formato markdown
3. Seja específico e objetivo
4. Inclua exemplos quando relevante
5. Mantenha atualizado

## 💡 Dicas

- Instruções mais específicas têm prioridade sobre gerais
- Evite instruções conflitantes
- Mantenha instruções concisas (quanto menor, melhor)
- Revise periodicamente para remover obsoletas
